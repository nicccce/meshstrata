## 独立安全收尾

原驱动的六份拓扑 JSON 末条均为 `topology_cleanup(errors=[])`。这是原驱动自报，不是主机审计。本轮以已登记身份做独立只读 SSH 清点，使用 `/proc` 和系统监听表核对，读取已有进程启动记录而不执行包内二进制。这份 [脱敏审计](T02-audit.json) 记录最终采样（北京时间 12:47:54–55）：

| 核对项 | Ubuntu 24.04 / Linux 6.8.0-49 | Alpine 3.23.7 / Linux 6.18.59 |
| --- | ---: | ---: |
| `/root/t02-1117a` 权限 | 0700 | 0700 |
| 原驱动 PID 启动记录 / 缺退出记录 | 81 / 0 | 54 / 0 |
| 本轮 bin 下活动可执行进程 / 仍属本轮的记录 PID | 0 / 0 | 0 / 0 |
| 原 TCP/UDP 监听与独立复核；地址/协议及监听者 PID、名称对比 | 14 → 14，无差异 | 2 → 2，无差异 |
| 本轮活动 Unix socket / 遗留非活动 socket 文件 | 0 / 5 | 0 / 3 |

无本轮公共代理监听、无本轮活动 Controller、Agent、Mihomo、helper 或回显进程；不需要发信号、执行 `stop-runtime` 或改宿主服务。复核端未发现本轮 SSH 复用 socket 或复用进程，新只读会话禁用了复用。未触碰非活动 `m.sock` 文件、原日志、私有配置及状态目录；文件存在不等同于有 Unix 监听。结论适用于抽查时点和当前主机可见的进程/监听范围。

两台的 COMMIT 和清单中全部 11 个固定产物与原两个辅助件的 SHA-256 匹配（常规三二进制为 Controller、Agent、Mihomo v1.19.33 Linux amd64）。单独计划追加的 `test/t02-artifact` 在两机均不存在；其本机文件摘要与本机独立清单匹配，没有远端部署或运行的通过证据。摘要、原始证据文件名及审计计数见附表；原始主机记录仅留忽略目录。
