### 可复现缺陷与有界修复

1. **请求相关性与槽生命周期**：旧 `recordObservation` 在核对 ID/期限之前清空槽。现在只消费当前 session 的精确 request；迟到替代报告不清新槽、不写证据；过期精确报告有安全期限码。发送失败释放自身槽，取消的调度上下文不发送。持久阶段仍核对 request 的 node revision/DNS/socket/target，以及事务内当前 Session/CAS；记录过程串行且最多5秒，避免交错写旧证据。正常重放/旧 Session 仍拒绝。
2. **失败观察隔离与退避**：旧 Agent 任何观察错误直接结束串行控制 worker，连同无关命令/回执一起断开。新增双方显式协商的 `meshstrata.control.v2.observation-status`；只允许三个白名单失败码，失败不能携带库存/出口成功，也从不进入 evidence store。精确失败立即释放槽，按 node revision + DNS Pin + target完整Pin分开 2/4/8/16/32秒有限退避；每连接至多128条临时调度元数据，不替代持久意向。新凭据 Pin、库存、其他目标不继承失败退避。命令/回执仍同一连接处理，Agent独立到期机制不变。base V2不接收新失败字段，旧V1不变；混合版本回退仍为原有界请求期限。本轮没有增加15秒观察期限、5秒单探针预算、原55/50/30/90秒外部界限或12秒到期拒绝门槛。
3. **新候选的策略引用**：仅保留剩余监听器 Forward.Terminal 的完整Pin；新发布策略在其后显式加入。过滤发生于新候选基线、入口cleanup及最后内部link退休。活跃监听器继续保留所有精确策略版本；新候选缺少其证据仍拒绝。没有删除目录策略/目标、历史Pin、已确认artifact/密文、Grant Origin、墓碑或端口账本；真实清理确认仍先于释放端口。原产品上的最小无引用旧HTTP策略回归稳定 /egress/evidence:NOT_FOUND，修复后真实新任务生成只含当前策略，旧已发布历史仍可读。

安全诊断仅记录 node/session/request ID、node revision、阶段、elapsed/age/TTL和白名单错误码；没有任意输入、错误原文、凭据、URL或完整配置。可区分连接不可用、busy/backoff、inventory/kernel gate、正确回显、负认证、source interface、local plan fence和事务接纳。单纯TCP成功仍不证明业务UDP。
