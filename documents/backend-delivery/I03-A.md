## Controller 边界

`releases.Service` 实现 `stage3.Infrastructure/Publisher`，不引入第二个数据库或独立调度器。准备、Pin hash、解密/加密、精确 V2 编码均在事务外；提交短事务重查节点 CAS、DNS/库存新鲜度、会话、审阅 subject、B08 generation/撤销与租约 fence。只用本次 Queries，无嵌套数据库回调。

- `RecordInventory` 只接可信本地 provisioner/Agent adapter：精确节点修订、DNS Pin、协议 socket Pin/池、LoopInventory 和真实接口观察。库存有效期有界，缺失/过期/不匹配失败。它不是管理 HTTP，也不宣告已认证 V2 能力。
- `NodeSnapshot` 读取真实 SQLite 与 B04 精确已确认产物，事务外按格式解密。区分原 ArtifactKey、effective digest、evidence time 与节点当前 CAS；不能用 effective 摘要代替原产物摘要。首次空状态明确为 `unconfirmed_empty`，不冒充 Agent 确认；有可能已应用、未知 Origin 或 restricted effective 状态时阻断。当前授权产生的 PendingTombstones 独立于原始确认产物，不改其 bytes/key。
- `ReserveIngress` 原 OperationID+摘要重放先于新鲜度/期限检查。固定配置的 preferred port 与每订阅独立实际 port 分开保存；优先 preferred，再在审核池内有界选择。第二订阅取得不同 listener/identity/port，绝不把原 NodeConfig RequestedPort 改成 0。两种端口账本的双栈重叠检查与 listener、legacy port、B06 lease、I03 lease 在同一事务提交；不镜像占用同一端口，不插虚假 entry grant。
- `ReserveLink` 先按完整后缀/请求摘要重放，事务外准备真实内部凭据，再同事务落真实 listener/端口/链接与引用。共享基于完整后缀与未退休状态。独立内部 Origin 在第一次 fetch 固定；后续产物复用同 link 必须保持完整身份绑定。内部 link 不借用客户 identity/expiry。
- `SubmitV2` 生成真实 TaskID 后编码/加密不可变原始 bytes，复用 B04 的 tasks、task_nodes、DAG、节点 CAS、密文 artifact、结果与 receipt。format=1 默认保留；format=2 有不可更新约束。每个发送链路要实际 `CheckLinkPair`，本任务内依赖真实下游节点，否则固定当前确认的 receiver revision/digest/epoch；arm/fetch 再查。所有当前内部 Origin 必须保留或有永久 retirement。
- V2 必须由可信认证会话 adapter 显式报告 recovery format=2，SessionID 每次重连变化。提交、arm、Resolve/Open、结果入口都检查能力；artifact 解密前后再次核验授权，Origin/fetched 只在最后提交时记录。旧 V1 decoder 不接 V2，未知格式拒绝。确认的 V1 baseline 目前整体拒绝切入 V2，显式迁移/轮换属于 B 的后续工作。
- V2 cancel/retry/rollback 分格式读取并保留原始 artifact/history；动作幂等记录和新 task 在同一事务提交，重复/丢回复返回原 TaskID。rollback 保留当前 tombstone/retirement，移除条目立即撤销下载授权，不恢复已撤销身份。B08 清理不用泛化 retry 绕过 fence，而是保持逻辑 cleanup operation，追加持久 generation/前次 TaskID，再编译新任务。终态、旧 receipt 与新任务独立，迟到结果不确认新任务。
- `CompensateUnarmed` 先封迟到 reservation/arm；只有所有相关目标均 queued 且 unfetched、无 Origin 才取消任务并确认从未武装，释放真实 lease/端口。无法证明时仍持久保存 fence，返回 `GRANT_ORIGIN_UNCERTAIN`，等待真实 cleanup。B08 清理确认后由 `SettleEntryCleanup` 幂等释放引用/端口，重启 sweep 可续办。
- `RetireInternal` 只允许 B06 最后引用退休后生成永久 link tombstone；receipt 前端口保持 pending，真实 Applied+Cleanup confirmed 落库后再确认/释放。退休请求幂等结果也与 task 原子保存。仍有 route/entry 引用时拒绝。旧 node-removal 的 V1 recompile 遇到 V2 明确 `NOT_IMPLEMENTED`，不能隐式降级；多节点 V2 removal 编排尚待后续集成。

出口观察只有固定数值 probe allowlist，不接任意 URL、脚本、网络扫描。`RecordEgressObservation` 核验真实 target Pin、node/DNS revision、短 TTL、库存中存在且 up 的接口/源地址、受保护 TUN/端点/网段回环，再持久证据与来源。Node Default 的 TCP 配置可编译；其他目标及业务 UDP 缺证据保持阻断。本批未做外部出口连通验证，注入观察只能证明适配边界。
