## 实现入口及确切接口

`internal/mihomo/config.go` 提供 `Version`、`LinuxAMD64SHA256`、`Protocol`、私密 `Entry`、`Expected`、`DNS`、`Config`、`BuildListener`、`Generate` 和 `Digest`。`Entry/Config` 含真实凭据，是 Agent 本地私密输入，不能作为普通 HTTP DTO、控制结果或日志对象。

```go
func BuildListener(e Entry) (Listener, error)
func Generate(entries []Entry, dns DNS, socket string, rules []string) (Config, []Expected, error)
func Digest(b []byte) string
```

每个 Entry 含 NodeID/ListenerID/IdentityID、协议、精确地址/端口与业务 UDP 检查要求。生成时拒绝重复 Listener/Identity；适配器校验还要求每个 Trojan/VLESS/Hy2 Listener 仅一个用户。SS2022/Hy2 永不共享，本轮 Trojan/VLESS 同样不共享。

`agent/internal/mihomo/adapter.go`、`evidence.go` 是独立本机适配器：

```go
type Options struct {
    Binary, BinarySHA256 string
    WorkDir, StateDir, ConfigDir, SocketPath string
    TCPAddress, Secret string
    Timeout time.Duration
    MaxResponseBytes int64
}
func New(o Options) (*Adapter, error)

type Candidate struct {
    Path, Digest string
    Expected []core.Expected // core = internal/mihomo
}
func (*Adapter) Validate(context.Context, Candidate) (Validated, error)
func (*Adapter) Startup(context.Context, Candidate) (string, []string, error)
func (*Adapter) Reload(context.Context, Candidate) (Applied, error)
func (*Adapter) Inspect(context.Context, Candidate, int) (Evidence, error)
func (*Adapter) Verify(context.Context, Candidate, int, Probe) (Evidence, error)
func (*Adapter) Connections(context.Context) ([]Connection, error)
func (*Adapter) CloseConnection(context.Context, Candidate, string, string) error
func (*Adapter) Revocation(context.Context, Candidate, RevocationProbe) (RevocationEvidence, error)
```

`Probe.Forward(ctx, expected, "tcp"|"udp") Check` 必须以预期身份认证并比较受控目标的返回载荷；`RevocationProbe` 分别实现 `OldAuthenticationDenied(ctx)`、`ExistingSessionsClosed(ctx)`、`OtherIdentityUnaffected(ctx)`。回调必须遵守 ctx。nil probe、未知状态或过期后返回的成功都不会成为 Verified；回调的自由错误文本不进入证据。

`Options` 默认超时 10 秒、配置/API 响应上限 1 MiB；显式范围分别为正数至 1 分钟、1024 字节至 4 MiB。HTTP 响应头限 8192 字节，禁止重定向和环境代理。TCP 可选项仅接受数值回环地址与非零端口，并要求至少 32 字节 secret；B05 应使用 crypto/rand 生成，本地保存，不经 Controller。默认 TCP/TLS 管理地址为空，仅 Unix API。

路径必须绝对、规范、无任一层 symlink。WorkDir/StateDir/ConfigDir/socket 父目录必须已存在且对组/其他用户无权限（推荐 0700；本轮不实现 0750 组共享策略）。配置及证书/私钥文件必须在 ConfigDir 内、普通文件且无组/其他用户权限，推荐 0600；内层目录同样受限。已有 socket 路径不能是 symlink/普通文件。库不替调用方 chmod、不创建缺失配置，也不读取其他实例配置。binary 必须可执行、不可由组/其他用户写入；Validate 按显式摘要核对。

`Validate` 接受受限 JSON（固定内核可按 YAML 加载 JSON），拒绝未知/重复字段、摘要不符、路径越界、一般入站/TUN/iptables/DNS 监听、不匹配的管理地址、多人 Listener、缺失协议字段和无显式末尾 MATCH 的规则。TLS 文件还检查密钥配对，最后执行固定 binary `-t -d <WorkDir> -f <Path>`；内核 stdout/stderr 全部丢弃，以稳定错误代替原始诊断。错误为 `MIHOMO_INVALID_OPTIONS`、`MIHOMO_UNSAFE_PATH`、`MIHOMO_CONFIG_MISSING`、`MIHOMO_BINARY_MISMATCH`、`MIHOMO_SYNTAX_FAILED`、`MIHOMO_API_FAILED`、`MIHOMO_RESPONSE_LIMIT`、`MIHOMO_INSPECTION_FAILED`、`MIHOMO_INVALID_CONFIG`（可 `errors.Is`），以及标准 context 取消/超时。协议字段错误是固定 JSON pointer 的 `core.FieldError`，不拼接秘密值。

`Startup` 验证通过后仅返回 binary 与 `-d/-f` argv，供平台实例管理器使用，不启动/停止生产进程；缺配置在启动命令生成前拒绝，避免默认 mixed-port。`Reload` 再校验候选后发送 `PUT /configs?force=true` 和绝对 path，只返回带摘要/时间的 API 应用尝试，不返回 Verified。B05 必须在整个操作中独占配置写入并保持候选不可变；本模块不提供原子启动配置/checkpoint/回滚。

`Inspect` 检查选定 PID 的 `/proc/<pid>/exe`、`-d`、进程启动标识以及 FD 的 socket inode，读取该进程网络表，核对精确 IP/端口/TCP/UDP。宿主另一进程占用同一端口不能通过。权限、进程不匹配或不可读状态会失败；这是 Linux /proc 实现，Alpine 运行尚待 T01。管理 API 可以先于业务 Listener 就绪；调用方须在任务截止时间内有界重试检查。

`Verify` 只有监听、认证 TCP 和要求的业务 UDP 探测全部成功才设置 `Evidence.Verified`。空 Listener 集合也不据此成为 Verified。`Evidence.Digest` 是本次预期候选字节摘要，不宣称读取到了内核内部配置摘要。每项证据明确 `success/failure/unverified`、时间、PID/启动标识、预期资源与所见 socket。

`Connections` 仅返回连接 ID 与 inboundName，隐藏目的地址等原始 metadata；`CloseConnection` 重新核对候选许可的 Listener 与当前连接归属，只删除指定 ID，绝不调用全量 DELETE。移除整个 Listener 后可用仍受信的上一候选来授权精确清理，不重新应用旧候选。B05 负责发布屏障、撤销集合与并发重查；一次连接快照不能保证没有晚到的旧会话。

## 配置及实测矩阵

生成配置显式将 port/socks/mixed/redir/tproxy 五项置零，allow-lan=false，TUN/iptables=false；dns.enable=true、dns.listen=""，明确传入 nameserver/default-nameserver，管理 TCP/TLS 默认空，profile 缓存关闭。默认生成器无自动 DIRECT 规则，规则须调用方显式提供。当前是 DIRECT/REJECT 内建目标的受限子集；完整多跳、代理出口、sub-rules、DomainSet、DNS 策略编译留 B04/B05，届时须审阅扩展本模型及 policy，不能绕过校验。

最终真实测试时间：2026-11-12 **17:26:53–17:27:08 +08:00**。每协议两个独立身份、两个独立 Listener；临时客户端同一固定 binary。TCP 随机载荷 64 字节，业务 UDP 独立 SOCKS UDP associate + IPv4 echo 载荷 32 字节。目的端点均受控回环地址，没有公网业务请求或流量压测。

| 协议/参数 | TCP / 业务 UDP | 坏凭据、新连接旧凭据 | 重载后的旧 TCP 数据路径 | 精确清理与另一身份 |
| --- | --- | --- | --- | --- |
| SS2022：2022-blake3-aes-128-gcm、16 字节随机 PSK 的 base64、udp=true | 均成功；外层 TCP+UDP | 均不转发且连接关闭；正确新凭据同端口可转发 | **仍能转发**，不能只靠重载撤销存量 | 捕获 3 个服务端会话 ID，精确关闭 3 个；已不存在且旧通道不转发；另一身份新连接/存量连接均成功 |
| Trojan：单用户随机密码、ECDSA P-256 临时 TLS 证书/密钥、客户端精确叶证书 SHA-256 pin | 均成功；外层 TCP | 同上 | **仍能转发** | 同上，3/3；另一独立 Listener 不受影响 |
| VLESS：UUID、xtls-rprx-vision、X25519 REALITY、16 hex short-id、test.local SNI、客户端 chrome 指纹 | 均成功；外层 TCP | 同上 | **仍能转发** | 同上，3/3；另一独立 Listener 不受影响 |
| Hysteria2：单用户随机密码、TLS 证书/密钥、叶证书 pin、默认 h3、无额外混淆 | 均成功；外层 UDP QUIC 与业务 UDP 分别验证 | 不转发；**新临时客户端强制新 QUIC**，明确取得固定客户端的 `authentication failed, status code: 404`，不以 SOCKS 超时/transport_error 单独作拒绝证据 | 旧通道不再回显；不宣称本地 SOCKS TCP 必然立即 EOF | 捕获 3 个服务端会话 ID，精确关闭 3 个；确认这些 ID 不再存在且旧通道不转发，另一身份新连接/存量连接均成功 |

最终四协议 `forward_verification.verified=true`、`revocation_verification.verified=true`。撤销中的 session scope 明确为**撤销前捕获的服务端跟踪会话消失 + 旧客户端通道不能转发**；这不是所有客户端传输 socket/QUIC transport 立即销毁的承诺。SS/Trojan/VLESS 的旧 TCP 要主动清理。Hy2 的外层已认证 QUIC 复用与一次全新认证是不同测试，已分别处理。

四种协议均实际制造冲突（前三种 TCP，Hy2 UDP）：另一临时进程持有请求端口，`Reload.APIAccepted=true`，但内核 PID 没有对应 socket，`conflict_inspection` 的新增 Listener 为 failure，不能成为 Verified。初始配置的所见网络监听均精确属于预期业务端点，没有一般入站/DNS/管理 TCP 监听。真实 Unix socket 为 **0666**，私有父目录为 **0700**，与固定版本行为一致；库不依赖 Unix secret 或 umask 隔离。跨 UID 访问拒绝没有另做降权用户实测，T01 可补。

SS2022 生成器还校验 AES-256-GCM/ChaCha20-Poly1305 的 32 字节 key 长度，但这两个 cipher **未做真实转发**。Trojan/VLESS 多用户共享 Listener **未验证，不支持开放共享**。业务 UDP 的域名/DNS、MTU、大包/分片、丢包、跨公网和多跳能力不在此次小流量 IPv4 回显结论内。


B05 先校验不可变产物与修订向量、合并单调墓碑/有效期，写受限候选并对**确切字节**计算 `coremihomo.Digest`。构造 Candidate 的 Expected 必须与生成的节点/Listener/协议/地址/端口/传输一致，不能以 Controller 普通 DTO 充当私密配置。生成器当前要求显式节点 DNS 与显式规则，不自动使用宿主 DNS 或 DIRECT。

B05 持有本机发布锁：Validate → 捕获需要撤销的旧 Listener/连接归属 → Reload → 用 B17 `platform.Manager.Status` 得到平台实例 PID → 有界 Inspect → 用候选身份/受控目标 Verify → 精确清理旧连接并重查 → Revocation → 持久 checkpoint/outbox。不得根据 HTTP2xx、端口存在、一次超时或旧连接仍可用认定成功；不得在尚未关闭应关闭的会话时释放资源。新身份尚未发布给用户时应建立发布屏障并重新枚举旧会话，处理捕获快照之后到达的旧连接；同 Listener 换代时不能误杀已开放的新身份连接。可使用独立新 Listener 来保持身份代次归属清楚，不能据此放开共享约束。

Probe 是可注入边界；本次具体协议客户端只存在于 opt-in 测试中。生产 Agent **没有**第二套 Mihomo 内核/临时客户端启动逻辑，B05/后续探测工作须提供符合该边界的受控轻量探针或授权外部探测结果；缺探针必须保持 unverified，不能接一个永远返回 success 的适配器。`Check` 到公共 `domain.Verification` 的聚合及任务结果/outbox 均由 B05 按既有契约处理，不新增公共状态字符串。
