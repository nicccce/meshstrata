# Meshstrata 前端页面集成验收

日期：2026-11-10。P01–P10 十个 `gpt-6.1-sol / high` 会话均已交付，由原设计会话在同一工作区完成集成。任务和会话 ID 见 [会话登记](会话登记.md)。各 `Pxx.md` 保留独立会话当时的检查结果，本记录描述最终集成状态。

## 集成修复

- 修复深只读 RouteRevision 导致的类型错误，统一测量时间口径和本地配对判断。刷新后没有内存 secret 的客户端不能继续显示为已配对。
- 订阅仍能引用失败编辑之前的 published 快照；新建路径使用固定端口时遇冲突不会静默换端口，自动分配遵守协议端口池。
- 线路向导成功路径移出草稿，失败路径保留；重试沿用稳定线路 ID。Node Default 清除 policy ID，避免误生成独立自定义出口分组。
- 增加类型化 `Draft.data.egress` 及持久化白名单。每个线路草稿/路径/末端节点隔离保存，认证信息不进入表单草稿。
- 外部预置 tun0 不再被通用 TUN 名称拦截；自身 Mihomo/loopback 接口仍有阻断提示，可达性保持 Not Checked。
- 规则目标包含已发布线路名称；附加 DomainSet 同时输出 MATCH 之前的 RULE-SET 和 DNS 映射。DNS 默认出站显式带目标，bootstrap 明确 DIRECT；REJECT 无可用 DNS 分组时阻止生成，不静默回退直连。重复生成的 UDP guard 被去重。
- 续期重新执行订阅身份隔离及端口分配校验，避免直接复活已清理入口；订阅模拟任务的应用/验证字段保持一致。
- 路由初始化完成后再挂载应用，避免初始标题翻译 undefined。补齐订阅名称/描述输入的标签关联，修复线路详情和规则编辑器在 390px 下的网格溢出。

## 验证

`bash controller/web/scripts/check-pages.sh` 通过，包含：

1. 19 个路由、query/returnTo、内存历史、六种 seed 场景与引用、持久化、草稿白名单及配对状态回归。
2. 跨页面逻辑：订阅入口隔离、Profile 线路目标、DomainSet 与 DNS 输出、旧发布版本保留、固定/自动端口、缺失测量及外部接口。
3. 活动任务：离线回滚、原始快照不可变、清理引用、Reverse 顺序、取消、版本不匹配与 UTF-8 日志边界。
4. Vue TypeScript 检查及 Vite 生产构建。

实际浏览器使用 Playwright 1.56.1 / Chromium 141，针对生产构建运行。宿主缺少浏览器和图形依赖，工具、库、字体均放在忽略的 `.local/browser-check` 内；未修改系统软件，也未增加应用运行依赖。

- 线路操作通过：候选选择 → 选项 → 出口抽屉草稿保存 → 刷新恢复 → Node Default → 校验与模拟发布 → 发布任务详情；已完成草稿被移除。
- 订阅操作通过：预选线路 → 输入资料 → 创建规则 Profile → 返回订阅 → 核对名称、线路和 Profile → 审阅 → 生成订阅；没有页面运行错误。
- 页面遍历通过 69 项：19 个常规入口、6 个缺失对象/未知路由、其余五种场景各 5 个主页面，以及 19 个入口的 390px 窄屏复查。运行时错误、自动业务 API 请求、页面横向溢出、控制台警告均为 0。逐文档重新加载，避免未保存弹窗使检查停留在旧页面。

可复用的浏览器脚本为 `controller/web/scripts/check-browser.cjs` 和 `controller/web/scripts/check-interactions.cjs`，需要单独安装 Playwright，并先启动生产静态预览。通过 `MESHSTRATA_PREVIEW_URL` 指定地址，`MESHSTRATA_PLAYWRIGHT_MODULE` 可指向隔离安装，`MESHSTRATA_CHROMIUM` 可指定浏览器。测试结果/截图默认写入忽略的 `.local/browser-check/results`。

## 后续接口实现边界

所有业务查询、分配、测量、发布、撤销、同步、日志和登录均为有限本地模拟；配置预览含占位认证，不能作为可用客户端配置。打开页面不自动请求业务接口；Settings 的 Controller 信息由用户显式查询。

以下状态有明确界面提示，不假装已经完成真实操作：

- Activity 的重试只更新任务记录，不重建历史线路快照、不自动释放仍有引用的端口；清理确认与离线节点同步需后续服务端协议。
- 共享出口策略的批量更新暂不可选，采用为当前线路保存独立策略并审阅发布。IPv6 与业务 UDP 的未验证能力不通过校验。
- 节点协议、probe、无引用 Listener 的未保存输入只保留当前编辑页，离开时提供丢弃/继续；节点基本资料、线路、出口、订阅和 Profile 支持显式保存草稿，DNS 使用独立待应用草稿。
- 本轮覆盖 Chromium 桌面及窄屏渲染与关键点击流程，未覆盖全部浏览器、全部键盘/辅助技术行为或真实设备网络。没有 Go 源码改动，未重跑后端部署/转发测试。
