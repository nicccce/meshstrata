# P11 — 简体中文 / English 多语言交付

日期：2026-11-11。前端位于 `controller/web`。保留进入本轮前已有的 Controller / Agent 目录迁移和节点一键命令、网络监管偏好改动；没有操作 Git index、提交、推送、清理或恢复旧 `web/`。

## 实现

- 保留英文，新增通用与全部 11 个 feature 的 `locales/zh-CN.ts`，覆盖 19 个命名页面、导航、状态、表单、错误/校验/成功提示、空态、抽屉、确认弹窗、辅助说明与无障碍标签。已知测量来源、计时依据、范围、目标类型及状态使用展示翻译，不改写持久化观测。
- Settings → 通用的“界面语言”提供“简体中文 / English”。选择即生效、立即保存到既有 `meshstrata.demo.v1` 的 `settings.locale`，不需要保存整组或重新导航。普通设置组保存不隐式建立语言偏好；语言字段不参与组内未保存编辑。
- 没有明确选择时使用浏览器首选语言；`zh` 及 `zh-CN/zh-TW/zh-HK/zh-Hans/zh_Hant` 等变体统一到 `zh-CN`；未知语言回退 `en`。已保存选择优先于浏览器；Reset Demo 保留明确界面语言，仍重置对象、草稿与内存秘密。
- `locale.ts` 只提供纯归一化逻辑。`i18n.ts` 读取工作区偏好，不让 workspace 反向依赖 i18n/Vite glob。启动时先选定语言再挂载页面，关闭英文资源回退以暴露缺项。
- Naive UI 的 `locale/dateLocale`、Intl 日期/数字、HTML `lang` 与当前 document.title 跟随语言。标题监听当前路由和语言，切换无需再次导航。补齐订阅列表、详情、编辑预览中原先直接调用无参数 `toLocaleString()` 的格式化。
- 使用“强监管 / 弱监管”，规范值仍为 `strong_regulation / weak_regulation`。新路由继续继承 Settings，单条草稿覆盖仍在默认折叠的“推荐偏好（可选）”；节点监管标签与客户端偏好独立，不按国家/IP 推断。
- 原有节点流程保持：资料 → 完整命令预览 → 复制后自动等待，逐项进度、失败重试、取消、过期与手动复制均保留，成功消费一次性命令。复制内容整体注释，不会执行真实安装。

协议/产品名、CLI 参数、规则语法、机器标识、代理组名和用户输入保持原值。已有对象名称、历史事件名称及观测结果不会因切换语言被翻译或重写；因此中文界面中的演示记录仍可有英文名称。

新增 `scripts/check-i18n-browser.cjs`，只使用已存在的 `127.0.0.1:5173` Vite 与独立 Playwright context，按页面实际加载的 Vite 模块 URL（含 HMR 时间戳）读取工作区，避免验收脚本创建第二份 Router/workspace。没有停止、重复启动或改成公网监听，没有使用用户浏览器存储。
