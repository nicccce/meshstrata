# P03 · Node Detail / Protocols / Target DNS

日期：2026-11-10（Asia/Shanghai）。本轮仅修改 `web/src/features/node-detail/` 与本文件；未 stage、commit、push、切换分支或操作其他会话。

## 实现范围

- `NodeDetailPage.vue` 保留动态 ID 查找和未找到返回列表；以节点 ID / resetEpoch 隔离编辑器。五个标签通过 `pageLocation` 写入白名单 tab，浏览器返回可恢复标签；切换标签保留当前输入。
- Overview 分开显示 Control / Tunnel / Route Verification，不通过资源查询修改协议验证。按需有限模拟查询 CPU、内存、磁盘、网速，显示 Last Confirmed / Last Queried / Unknown / Stale，部分场景缺值保持 null。失败保留上次成功快照并支持重试。
- 节点编辑使用 `useDraft` 和既定 `Draft.data.node` 字段；支持保存、保存草稿、丢弃、刷新恢复、路由离开保护。位置更新保留 manualLocation。Direct 地址变化过期关联测量。
- Protocols & Ports：唯一来源 `protocolDefaults`；兼容旧快照补齐四协议默认值（Reverse 仅 SS 2022 TCP / loopback）。支持启用、自动/固定首选端口、地址、附加端口范围、按协议展开公共参数。显示业务 TCP / UDP 与外层传输的不同含义。校验固定端口占用、TCP/UDP 冲突、范围、公钥、short ID、SNI；不静默改端口。引用存在时一次影响确认，明确实际 Listener 不变。
- 下区为实际 Listener：搜索、实际端点、传输、下一跳/线路版本提示、引用、发布/清理状态。Inspect 列出线路、订阅、隧道依赖并跳转。共享 Listener 阻止原地改写，引导线路编辑完成资源迁移；无引用 Listener 可执行模拟发布，结束前重新核对依赖和端口。
- Target DNS：明确应用版本 targetDns / dnsRouting 与待应用 dnsDraft；实例级上游、显式出站、启动解析。保存草稿不修改应用态。HTTPS/TLS/IP 校验拒绝认证 URL、query 和 fragment；域名上游要求 bootstrap IP，不回退宿主 DNS。Review 展示影响和修订；有限可取消模拟发布写入共享 Release / Event。成功才推进应用版本，过期关联 DNS / destination / egress-IP 检查并失效线路草稿验证；失败保留应用版本和 DNS 草稿。
- Connectivity：Direct 可保存 HTTPS 探测端点、启停、配置修订及模拟检查；配置变更仅过期 Browser HTTP / path-cost 缓存。无 fetch、socket、本地 API 或证书部署。Reverse 分开呈现固定 Relay、TCP+mTLS、远端 loopback Listener、本地端口、Relay loopback mapping port、修订及两端配置确认；显示真实隧道 RTT Not Measured。模拟结构检查不修改完整线路验证。
- Routes：搜索、入口/中转/出口筛选、发布状态筛选、空/无匹配状态、清除筛选、线路详情和关联列表跳转；创建线路预填 exitNodeId。
- Remove 一次影响确认列出线路、订阅、管理身份、隧道和 Listener；只软移除，保留引用和端口、线路路径不变。节点离线、资源/条目 Pending Cleanup、订阅 Pending Sync，创建撤销任务及事件；没有自动换路。
- 所有界面文案在本 feature 英语 i18n；使用 Naive UI、scoped CSS、窄屏堆叠、表格局部滚动和可聚焦校验摘要。任务取消与页面离开/切换节点/Reset Demo 关联。

## 默认值与契约缺口

1. 可选资源/版本/时间缺失显示 Unknown / Not Queried；不把 updatedAt 当作连接确认。当前模型只有 lastConfirmedAt，没有独立 controlObservedAt / tunnelObservedAt，Tunnel 时间显示 Unknown；Route 时间仅取关联线路 verifiedAt。
2. 缺少协议可选值时，autoPort=true、Direct 监听 0.0.0.0、Reverse 127.0.0.1 TCP；协议默认端口 SS 22001、Trojan/Hysteria 22443、VLESS 22444。无附加范围时说明 node / system pool fallback。
3. 缺少 dnsRouting 时显式 direct、bootstrap 空；历史应用配置仍照实显示，发布新域名上游前必须补齐 bootstrap。缺少 probe 时 disabled / revision 0。
4. `DraftData.node` 只支持节点 Basics，没有 protocolDefaults、probe、Listener 编辑字段。因此这三种编辑器仅保留当前页面未保存输入并提供 Stay / Discard 离开保护；没有塞入其他 Draft 字段，也没有自建 localStorage。后续集成如要求这三类 Save Draft，建议在 DraftData 增加类型化字段并扩展投影。DNS 使用共享契约专设的 Node.dnsDraft，不另建镜像草稿。
5. ReverseTunnel 无撤销/cleanup 字段；移除通过保留 tunnel 记录、取消两端 applied 确认和创建 pending cleanup Release 表达。后续建议增加独立授权撤销及两端清理状态，才能精确表达 Relay 已拒绝/远端仍未知。
6. shared Listener 修改遵循产品 2.9：不能全局原地改写带引用资源。迁移由线路编辑模块负责，本页提供明确依赖与入口。
7. Relay enabled 缺失按已注册 both-role Relay 可用解释；不自行配置 Relay 或安装任何服务。
