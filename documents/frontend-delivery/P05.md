# P05 — 四步线路创建与编辑

日期：2026-11-10（Asia/Shanghai）。修改范围仅 `web/src/features/route-editor/` 与本记录；无 Git 暂存、提交、推送，无新会话/子代理、API、服务或依赖安装。

## 已实现

- 新建/编辑四步向导，URL step、固定底栏、持续摘要、搜索、空态、缺失动态 ID 与错误阻断；英文 feature i18n，Naive UI 与 scoped 窄屏样式。
- 出口优先，读取 Settings 可选默认值；外层 UDP 与业务 UDP 分开。Reverse 固定本地 both Relay → remote、内部回环 SS 2022 TCP、独立 Relay mapping，拒绝业务 UDP 和高级插入节点。
- 默认最多三条节点路径去重候选，可调整数量、展开入口协议替代、多选独立命名；已有网络 RTT 边按非负权最短路径计算不同入口候选；无边时给未完整测量的人工候选，不宣称全网最优。手工入口/中转支持键盘上下移动。
- 三种测量分区，显式模拟 Measure Missing/Remeasure/Cancel、失败保留旧观测、Network Changed 使首段过期。展示方法/transport/样本/离散/时间/expiry/Path Unverified；null 和 stale 不当零；Browser 使用 Resource Timing 口径，Fetch Duration 不混排。Reverse 隧道 RTT 保持 Not Measured。
- 每条路径完整保存在既定 `Draft.data.route`，使用 useDraft 保存/丢弃/刷新恢复/离开保护。更改路径、命名、上游参数与引用资源使验证失效；不另存 localStorage。
- 高级区逐跳协议、共享 Listener 显式选择与独立 Listener/端口分配，固定端口冲突拒绝；分配资源以共享 Listener/Tunnel ID 关联草稿，发布端口与偏好端口分开。
- P06 stable EgressPolicyDrawer 的 save(policy) 接入本路径草稿。已有策略另存新 ID，不覆盖任何已有策略；策略变更涉及发布 Listener 时分配独立路径资源。选择已有策略显示发布引用数；不另存线路 DNS。
- Review 展示路径/修订/Listener 差异、节点/订阅跳转、端口/映射/防火墙、业务能力、真实认证 Not Checked；显式 frontend validation 后才允许模拟发布。
- 每条线路独立生成共享 Route/Release/Event。成功分开记录 applied/verified 与 stages，并推进 published；失败记录 rollback confirmed/pending/failed，保留旧 published 和其验证信息。可选择可复现全成功/失败/部分成功场景。单条完成跳 release-detail；多条逐条结果提供任务、线路和创建订阅入口，不冒充原子成功。应用前可取消，应用阶段等待有限模拟完成。

## 资源与共享契约说明

- Draft 路径只允许保存 RouteRevision，实际端口与 mapping 按既有共享 Listener/Tunnel 保存。显式分配会创建 `state: draft` 的独立 Listener；未采用/丢弃的暂存资源保留，不能在没有全局引用清理器时误删别的草稿资源。后续集成可增加草稿资源归属和安全清理机制。
- 新建恢复兼容 P04 使用 `feature: route` 的复制草稿；编辑仅修改一条线路，新建允许多候选批量创建。
- 未扩展共享类型；模拟测量仍缺完整浏览器上下文/endpoint revision/tunnel identity 字段，故不复用旧浏览器会话的真实能力声明。所有 method 和页面文案明确 simulated。
- 前端“验证通过”只代表离线结构与引用校验，不代表真实 Listener、协议、DNS、隧道或网卡可用。
