# P08 · Rule Profiles 与 DNS 映射

本轮仅修改 `web/src/features/rule-profiles/` 与本交付记录。未操作 Git index、提交、推送、分支或 worktree；未修改共享层及其他 feature；未创建子代理或向其他会话发消息。

## 完成范围

- 列表：英文二级导航、名称/说明搜索、URL 白名单 q/sort/page/pageSize、排序和分页；名称、说明、更新时间、修订和订阅引用；新增、编辑、带新 ID 的复制、上下文预览、删除确认。已引用方案列出订阅并跳转订阅 Policy 进行替换；订阅草稿引用也阻止删除。空列表、搜索无结果、缺失对象、失败场景和 stale 提示。
- 编辑：名称唯一性、长度校验、说明、规则原文、目标插入/域名规则辅助、兜底选择；Parsed Rules / DNS Mapping / Service Domain Sets / Validation 四个标签；错误行可定位文本，保存失败保留输入。原始输入通过 `useDraft` 的 `Draft.data.profile` 保存，并提供列表恢复/删除草稿；共享离开保护和刷新保护保留，另补同路由不同 profile/draft 参数跳转的 Save Draft / Discard / Stay 保护。
- 语法：明确支持 DOMAIN、DOMAIN-SUFFIX、纯域名 RULE-SET、IP-CIDR、IP-CIDR6、PROCESS-NAME、PROCESS-PATH、DST-PORT、SRC-PORT、NETWORK、MATCH。仅 IP 类允许 no-resolve；支持独立行、rules: 列表段、整行注释及整体引号包围的规则。不声称支持完整 YAML 或通用 Mihomo 编译；DOMAIN-KEYWORD、逻辑表达式、远程 rule-provider、端口区间、内联注释等均不接受。
- MATCH：单个自动提取；多个在所有对应行报错，并要求显式点击选择。生成规则在用户有序规则之前放 NETWORK,udp,REJECT，末尾恰好一个 MATCH。保存方案时仅规范化原文中的 MATCH 为唯一末尾规则；草稿保持未规范化原始输入。业务 UDP 防护始终开启，无未经逐跳验证的开启入口。
- 目标与上下文：从共享 workspace 派生已发布线路；出口组统一调用 `domain/groups.ts` 的 exitGroupName，检查节点、策略终点及策略修订。选择 subscriptionId 后按所选订阅的线路、分组选项和组成员检查，缺失目标给出规则行与名称；过期/撤销上下文提示，不宣称重新激活。未选上下文明确提示全局存在不代表该订阅生成该组。
- DNS：DOMAIN、DOMAIN-SUFFIX 与已选择纯域名集合派生有限域名绑定；进程/IP/端口/NETWORK 明确提示无法推导 DNS 出口。检测域名与后缀/集合重叠：同目标警告，跨目标错误阻止方案保存，不自动改顺序、目标或 no-resolve。区分 REJECT 阻断和显式 DIRECT；说明节点级 Target DNS、自定义 IP 出口、外部代理再次解析及应用 DoH 的边界，不声称观察到实际 DNS 路径或公网 IP。
- DomainSet：创建、编辑、共享引用展示、删除依赖检查；新增稳定英文 identifier，编辑时锁定；成员必须为不重复纯域名；保存递增修订并用共享 commands 更新。方案和草稿的已选集合与显式 RULE-SET 原文引用均参与删除保护。编辑当前选择中的集合必须先解除选择，保存共享变更前可见影响提示。新集合自动附加当前编辑器；未显式放置的已选集合生成规则位于用户规则之后、MATCH 之前。
- 所有读对象均来自只读 workspace；提交对象为新建或克隆，由 commands 写入。没有业务 API、网络探测、本地 API、下载脚本、安装、部署或远端写入。凭据键/带身份 URL 输入在写入草稿前被拒绝，没有新增 localStorage。

## 草稿往返约定

- 接收 `profile-new/profile-edit` 的 draftId、returnTo、subscriptionId；returnTo 使用共享 safeReturnTo 二次校验，只对订阅新建/编辑入口返回 profileId，同时保留原 URL 的 draftId/step 等白名单字段。
- 如果传入 draftId 指向带 `data.subscription` 的订阅草稿，P08 派生独立 profile 编辑器 draft ID，保留订阅原草稿。若传入已有 P08 草稿则直接恢复。同 ID 属于其他对象/feature 时显示错误，不覆盖。
- P08 不导入 P07 的私有逻辑。上下文只验证持久化的 subscriptionId 对应对象；订阅尚未保存的线路/分组变化仍需 P07 Review 再校验，页面已有此边界提示。列表恢复草稿不恢复 returnTo，因为共享 Draft 白名单没有该字段；原返回路径仍可由完整编辑器 URL 保留。
