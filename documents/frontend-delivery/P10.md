## 完成范围与具体行为

- Settings 八组通过白名单 `section` query 导航；桌面分组侧栏、窄屏选择器，仅显示当前组。每组独立 Save/Discard、字段错误、dirty 标签；切组、浏览器返回及离开页面有 Save/Discard/Stay 提醒，刷新使用原生未保存提示。保存仅向 `commands.updateSettings` 提交当前组 patch，不带其他组未保存值。
- General：环境、UDP transport 与 business UDP 独立控制，成功缓存缺省 96h、失败缓存 5min；英语界面与日期默认说明。保留原 `ControllerInfo`，仅它的显式按钮可选查询现有 Controller API，不自动查询。
- Ports：缺省 20000–29999、Web 8443、control 9443；整数范围、池顺序、保留端口冲突校验。展示 workspace 现存 Listener 并链接节点 Protocols。保存只是新资源计划，不改变实际监听或发布。
- Relay：固定 `settings.relayNodeId`，只允许已注册、未移除的 direct/both Agent；无任意节点选择。TCP+mTLS、127.0.0.1 映射池、SS 2022 TCP、无业务 UDP 的限制明确。保存不能排除现存 mapping port；被引用隧道阻止禁用。展示远端节点与受影响线路链接。旧快照无映射池时，用 30000–30999 包含已有端口的并集作为可编辑 fallback，保留旧映射。
- Location：provider、只存内存的 key、保留手工覆盖策略。有限的演示查询展示共享节点位置并链接节点；不改写节点，不访问位置 API。失败保留上次查询时间；空节点和 stale 场景有说明。
- Certificates：域名校验、DNS-01/provider/内存凭据、导入 PEM（私钥可显式切换多行显示）、输入形状审阅与时间。证书状态始终 Not checked；不假装签发/导入/加密验证成功。轮换影响模态先展示候选节点和协议入口，明确公共 TLS、管理 CA、REALITY 与隧道身份用途分离。
- Local Client：缺省回环 `http://127.0.0.1:9090`，仅接受无路径/凭据/query 的 loopback HTTP(S) URL；精确 allowed origin 校验。配对/解除配对是可取消的有限模拟，写入共享 `localClient.paired` 演示标记；秘密仅 `sessionSecrets`，不发本机请求。编辑地址/origin 后保存取消已有配对。原始 RTT 只是辅助偏好，不产生测量数据。
- Logs：warning/error、5MiB×4（含当前）、20MiB、7d；数值与总量校验。debug 必须填 1–60 分钟，保存 deadline 与之前级别；打开 Logs 或显式 Check expiry 后到期恢复。没有轮询、常驻计时器或后台服务。链接 Activity logs。
- Admin/Login：单账号 admin、初始演示密码 demo-only、修改密码/确认/当前密码校验。新密码仅内存，刷新/退出/Reset 后回到默认；无用户角色系统。登录支持显示密码、失败、取消和安全 returnTo；默认 Enter Demo 不要求密码，error 场景仍可进入。无路由鉴权伪装；退出清除内存秘密并回到 Login。
- 秘密输入通过 computed 读写 `sessionSecrets`，不放进 form/settings/Draft/query/toast；临时输入在保存/撤销/切组/离开/reset 清理；配对 secret 在解除配对/退出/reset 清理。i18n 全部位于 feature 英语资源；样式 scoped。

## 契约缺口与集成项

1. `DraftData` 当前只有 node/route/subscription/profile，没有 settings 类型及其投影。因此未伪造 `Draft.data.settings`、未塞进 name/text 或另建 localStorage；设置未保存编辑仅页面内存，离开需要处理。若要求设置跨刷新 Save Draft，集成应先为每个 section 增加精确非敏感 typed draft 与 `projectDraftData` 白名单，再接 `useDraft`。
2. Settings 没有日期格式字段；当前明确使用共享 `useFormat` 的 locale/本地时区，仅提供 English。自定义日期格式需要共享 Settings 及格式化 composable 支持。
3. 节点模型没有独立 Controller 部署角色/本机注册身份字段；以共享指定 `relayNodeId` 对应 direct/both 节点作为本地条件，不声称真实安装检查。证书没有证书实例/用途归属/到期时间，因此轮换列出可能消费者，不能给出精确证书引用或实际到期信息。
4. `localClient.paired` 可持久化，而 sessionSecrets 不可。P10 只有当前 tab 有配对 secret 时显示 Demo paired；其他功能若只判断 persisted paired，刷新后可能仍显示配对功能。集成应统一“演示配对标记”与“本 tab 可用配对”的语义，或提供公共 session pairing 状态；当前未越界修改消费者。
5. 短时 debug 到期检查按显式动作/进入页面执行，关闭页面时不运行服务。生产自动恢复属于后端；当前文案明确演示边界。
