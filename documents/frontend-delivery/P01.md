## 具体行为与口径

1. 登记节点排除 `removedAt`；已发布线路按 `published` 存在且无 `withdrawnAt`，保留失败尝试之前的已发布修订；有效订阅要求 active/expiring 且到期时间晚于当前时间。订阅卡打开完整列表，因为共享 status query 没有 active + expiring + future expiry 的组合口径。统计在进入、工作区改变及页面焦点交互时更新，无计时轮询。
2. 待办覆盖发布草稿、离线控制连接/Reverse 隧道、临近到期、到期/撤销待确认、离线待同步、Rollback Pending/Failed、发布失败及 Pending Cleanup。已确认撤销的过期订阅不会继续报撤销待办。共享 Release 优先承载回滚与清理，避免重复显示同一路由级工作；没有任务时回退对象详情的精确 tab。Listener 与订阅条目清理也有入口，已撤回线路的遗留清理仍可到达。
3. 待办支持名称/稳定 ID/分类搜索、分类筛选（含各类数量）、每页六条与清空筛选。无待办和筛选无结果分别提示。路线保存草稿用 `draftId` 与白名单 step 恢复；已有待发布路由不重复计算其草稿。未推断其他 feature 私有草稿入口。
4. 最近五个 Event 按更新时间排序，包含时间、结果、对象和精确任务链接；对象历史用 `activity?tab=events&entityType=...&entityId=...`。另列最近三个 Release，关联线路/订阅/节点。历史引用已删除对象时显示提示并保留原 ID 链接，让目标页维持 Not Found 行为。所有位置均通过 `pageLocation` / `entityLocation`，未扩展 query 白名单。
5. 引导按无登记节点 → Add Node、有节点无已发布修订 → Create Route、有已发布修订无订阅 → Create Subscription。完成配置后不显示阶段面板。Controller 信息降为 Settings General 链接。
6. 快照默认呈现最近已有用量所在订阅（若没有则首个登记节点），不自动开始查询。Refresh 前始终显示类型、明确单对象范围与无网络说明。选择不同范围清理本地读取反馈；重置 Demo 清理选中对象和反馈。对象已不存在时显示 missing，不暗自切换其他 ID。
7. Refresh 是有限、可取消的 500ms 模拟缓存读取；复用 `useQueryState` 与 `useSimulatedTask`。不会制造新测量、补造缺失资源、改业务记录或把旧观测时间重写为当前时间。单独记录 Last local read；刷新失败保留此前成功结果。Error/Offline scenario 或选中离线节点产生确定失败。取消及离开页面停止模拟计时。
8. 未知数据维持 Unknown；资源显示 CPU、内存/磁盘已用字节和网络速率快照；用量逐条展示 scope、metric、覆盖区间、完整性与 reset，不混加不兼容数据；测量保留 method/environment/transport/scope/revision/samples/原时间与有效期。每类最近最多四条，详情可查看其余记录。没有连续采样图。
9. 资源/用量缺少显式 expiresAt，页面采用共享 `measurementTtlHours ?? 96` 作为 UI 缓存陈旧提示窗口，文案明确窗口；不据此修改记录。测量直接使用各自 expiresAt。缺失可选资源、查询时间、metric 等均提供 Unknown/Not Queried/cumulative_bytes fallback。
10. 响应式布局在 1100px 以下待办/最近操作改为单列，760px 以下统计/筛选改为单列。使用真实 RouterLink、表单 label/input id、局部 aria-live、分页名称和可见文字状态；主要操作及输入/选择控件提供约 44px 触控高度。
