# P09 — Activity 与发布任务

范围：仅 `web/src/features/activity/` 与本交付文档。未编辑共享层、兄弟模块，未 stage/commit/push、更改分支或创建会话。

## 已实现

- Activity 的 Events / Releases / Node Logs 使用 `tab` 白名单 query；搜索、动作、精确对象类型/ID、结果筛选、排序和分页写入 URL，保留浏览器前后导航。时间筛选仅页面内状态，不添加未约定 query。缺失对象保留精确 ID 链接与提示，不跳到另一对象。
- 发布列表区分任务结果、Applied 未验证、Node Sync Pending、Pending Cleanup；事件能精确进入任务及来源。Error 场景显示读取失败并保留 workspace 记录；空结果可清除筛选。
- 日志先选择节点、组件、行数和 UTF-8 字节上限，再显式 Load；无自动拉取、跟随或网络探测。Agent/Mihomo/frps/frpc 可选项受节点类型限制。共享模型没有日志集合，因此输出明确标为从共享事件/任务/配置构造的演示运维摘要，不冒充进程日志。改变范围/离开/重置取消有限任务；失败保留上次成功结果，Stale 场景提示过期快照。
- 详情展示来源、期望修订、可选起止时间/草稿 ID、逐节点 Applied / Verified / rollback / issue 字段及节点日志跳转。旧 F00 任务无 stages 时不伪造结果；提供清晰的依赖参考顺序。正常发布后续节点先于入口；Reverse 明确远端 Listener、Relay 授权、隧道映射、映射认证转发、入口、完整验证顺序。
- Retry、回滚、清理重试、允许的预应用取消均为有确认影响提示的有限本地模拟，通过 commands 保存共享 Release/Event。重试已在回滚的任务只继续回滚；已有确认保留为历史，离线/缺失/移除节点不能获得新确认。来源缺失和期望修订不可用时拒绝推进。
- 回滚创建独立 Release，原任务记录与修订保留。取消只允许 draft/validating 且无应用证据，使用精确 CANCELLED issue 表示；已应用后提供回滚。清理独立于发布结果，重试不重复减少引用，不删除资源或释放端口。
- 模拟完成前检查任务、相关依赖和 reset epoch，防止其他页面更新或 Reset Demo 后覆盖新数据。任务动作不会覆盖源线路 published、订阅到期/撤销、入口身份、引用数组或外部资源。
- 英文 feature i18n、Naive UI、scoped 浅绿样式、窄屏单列和表格局部横向滚动、键盘可操作的控件与日志输出。

## 契约缺口与保守行为

1. Release 没有精确资源归属、清理逐资源确认、parent release / attempt history、取消状态字段。建议后续增加 `resourceRefs`、逐资源 cleanup、`parentReleaseId` 与 cancelled 状态。当前不根据宽泛 source ID 删除资源；相关 Listener/tunnel/entry 仍有引用或无法归属时显示 Pending Cleanup，保留端口。回滚另建任务但没有结构化 parent ID。
2. 没有 NodeLog 模型或演示日志集合。当前日志是明确标识的共享记录摘要；真实日志接入需约定组件、采集时间、截断及 byte/line 口径，继续保持显式加载。
3. Release 的订阅 revision 没有对应不可变订阅配置快照。任务只模拟节点结果，不推进源对象发布修订或将 revoked/expired 重新授权。完整发布提交由创建任务的模块/后续集成协调。
4. optional stages 使用既有记录顺序显示，重试模拟按内置依赖计划检查节点后更新未完成阶段，不将历史 succeeded 当成当前在线证据。
